# Nom 
AfriShop 

## Description

AfriShop est une boutique en ligne spécialisée dans la vente de produits africains. Son site vitrine présente :

- Une page d'accueil avec présentation
- Un catalogue de produits avec images, descriptions et prix
- Une section contact avec adresse et horaires
- Un design responsive et moderne
